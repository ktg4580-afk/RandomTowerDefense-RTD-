# 게임 규칙 초안 (회의 후 확정)

## 확정된 방향
- 1대1 실시간 타워 디펜스 (각 PC에 클라이언트 실행)
- 각 화면은 상단 상대방 / 하단 자기 필드
- 기본 몬스터는 자동으로 생성되며 양쪽 플레이어의 경로는 별개
- 동일 자원을 자기 주사위 소환·강화 **또는 상대 필드에 엘리트 몬스터 소환**에 사용
- 엘리트 몬스터는 여러 종류 중 랜덤으로 선택되어 상대 필드에 등장
- Java 최신 버전 사용 (팀이 동일 버전으로 설치한 뒤 정확한 버전을 여기 기록)

## 회의에서 확정할 항목
- 주사위 종류, 합성/강화 방식, 소환 비용
- 기본 몬스터·엘리트 종류, 공격력·체력·이동속도
- 엘리트 소환 쿨타임·비용·처치 보상
- 웨이브 간격과 몬스터 경로
- 게임 시작 체력, 종료 처리, 동시 패배
- 서버 전투 판정·상태 동기화 방식

## 개발 상태
- [x] TCP 접속/2인 참가/준비/시작 알림/채팅 데모
- [ ] 게임 화면/주사위/몬스터/엘리트/실시간 상태 동기화
