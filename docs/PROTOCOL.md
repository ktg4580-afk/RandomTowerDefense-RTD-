# 통신 규약 v0.1 (구현된 부분만)

- TCP, UTF-8, 한 줄에 명령 하나 (`\n` 구분)
- 각 클라이언트의 첫 명령은 `/JOIN 닉네임`이어야 합니다.
- 닉네임: 1~20자, 문자/숫자/`_`/`-`만 허용; 중복 금지
- 채팅: 120자 이하, 줄바꿈 금지

| 기능 | 방향 | 명령 및 예시 | 서버/클라이언트 처리 |
|---|---|---|---|
| 게임 참가 | C → S | `/JOIN Player1` | 빈 자리와 중복 확인 |
| 참가 승인 | S → C | `/JOIN_OK 1` | 플레이어 ID(1 또는 2) 표시 |
| 참가 거절 | S → C | `/JOIN_FAIL ROOM_FULL` | 접속 종료 |
| 대기 인원 | S → 양쪽 C | `/WAIT 1/2` | 현재 인원 표시(로그) |
| 준비 | C → S | `/READY` | 본인 준비 상태 변경 |
| 시작 | S → 양쪽 C | `/START` | 양측 준비 완료 표시(게임 플레이는 미구현) |
| 채팅 | C → S | `/CHAT HELLO` | 서버가 발신자 ID 부착해 전달 |
| 채팅 전달 | S → 양쪽 C | `/CHAT 1 HELLO` | 수신 메시지 표시 |
| 퇴장 | S → 남은 C | `/PLAYER_LEFT 2` | 상대 연결 종료 알림 |
| 오류 | S → C | `/ERROR UNKNOWN_COMMAND` | 로그로 확인 |

## 앞으로 설계할 프로토콜 (아직 미구현)
- `/SUMMON`: 주사위 랜덤 소환 요청
- `/MERGE`: 주사위 합성 요청
- `/ELITE_SUMMON`: 공통 자원으로 상대방에게 랜덤 엘리트 소환
- `/STATE`: 서버 기준 게임 상태 동기화
- `/WAVE`: 웨이브 시작
- `/HP`: 체력 변동
- `/GAME_OVER`: 승패 판정

**중요:** 각 메시지의 좌표/ID/능력치/비용 필드는 팀 회의에서 확정하기 전까지 임의로 구현하지 않습니다.
